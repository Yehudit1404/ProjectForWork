# לוח מודעות שכונתי — Neighborhood Classifieds Board

אפליקציית SPA ללוח מודעות שכונתי: חיפוש וסינון מודעות (כולל סינון לפי מיקום
נוכחי), ויצירה/עריכה/מחיקה מלאה (CRUD) של מודעות מול REST API. הפרויקט בנוי
לפי [מסמך האפיון המפורט](./docs/spec.md) שצורף למטלה.

| חלק | טכנולוגיה |
|---|---|
| **Client** | Angular 18 (standalone components) + Angular Material + Leaflet |
| **Server** | C# / ASP.NET Core 8 Web API |
| **אחסון** | קובץ JSON יחיד בצד השרת (`server/Data/Storage/ads.json`), ללא מסד נתונים |
| **מפות** | OpenStreetMap + Leaflet (חיפוש/מיקום דרך Nominatim) — **ללא מפתח API, ללא כרטיס אשראי** |
| **בונוס** | שיוך מיקום למודעה (חיפוש כתובת + מפה אינטראקטיבית) וסינון/מיון מודעות לפי מרחק מהמיקום הנוכחי |

## שיפורים נוספים מעבר לדרישות הבסיס

- **תצוגת מפה כוללת** — כפתור החלפה בין תצוגת רשת לתצוגת מפה בלוח הראשי: כל
  המודעות עם מיקום מוצגות כסמנים על מפה אחת, מקובצות אוטומטית לפי זום
  (Marker Clustering, בעזרת `leaflet.markercluster`), עם חלון תצוגה
  מקדימה (תמונה, כותרת, מחיר) בלחיצה על סמן.
- **מצב לילה (Dark Mode)** — מתג בכותרת העליונה, עם ערכת נושא כהה מלאה
  (כולל רכיבי Angular Material) ושמירת ההעדפה בין ביקורים.
- **אנימציות ומיקרו-אינטראקציות** — מעברי דהייה בין עמודים, כניסה מדורגת של
  כרטיסי המודעות ברשת, ואפקטי ריחוף/לחיצה עדינים בכל האתר.
- **תמונות דוגמה מקומיות** — לכל מודעת seed יש איור ייעודי שנוצר מקומית
  ונשמר בקובץ אמיתי תחת `server/Data/SeedImages/` (לא מגיע מהאינטרנט),
  ונטען ומוטמע (Base64) לתוך המודעה בעת יצירת קובץ הדוגמאות.

## הרצה מקומית

### דרישות מקדימות

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Node.js](https://nodejs.org/) 20 ומעלה (נבדק עם Node 22) + npm
- **שום דבר נוסף** — בונוס המיקום (מפה, חיפוש כתובת) עובד מיד, ללא הרשמה,
  ללא מפתח API וללא כרטיס אשראי (מבוסס OpenStreetMap/Leaflet במקום Google Maps).

### 1. הרצת השרת (API)

```bash
cd server
dotnet run
```

השרת יעלה בכתובת `http://localhost:5093` (ניתן לשנות ב-`Properties/launchSettings.json`).
בהרצה הראשונה ייווצר אוטומטית קובץ `server/Data/Storage/ads.json` עם כמה
מודעות לדוגמה. בסביבת פיתוח זמין גם ממשק בדיקה אינטראקטיבי של ה-API בכתובת:

```
http://localhost:5093/swagger
```

### 2. הרצת הקליינט (Angular)

בטרמינל נפרד:

```bash
cd client
npm install
npm start        # שווה ערך ל- ng serve
```

האפליקציה תיפתח בכתובת `http://localhost:4200` ותתחבר אוטומטית ל-API בכתובת
`http://localhost:5093/api` (מוגדר ב-`src/environments/environment.ts`).

> אם משנים את הפורט של השרת, יש לעדכן בהתאם את `apiBaseUrl` ב-
> `src/environments/environment.ts` (וב-`environment.prod.ts` אם קיים),
> וכן את `Cors:AllowedOrigins` ב-`server/appsettings.json`.

### 3. פיצ'רי המיקום (מפה, חיפוש כתובת) — ללא הגדרה נוספת

בשונה מ-Google Maps, אין כאן שום מפתח API להגדיר: המפה מבוססת [Leaflet](https://leafletjs.com/)
עם אריחי מפה חופשיים של [OpenStreetMap](https://www.openstreetmap.org/), וחיפוש/תרגום
כתובות מתבצע דרך [Nominatim](https://nominatim.org/) — שירות החיפוש החופשי
של OpenStreetMap. שני השירותים פתוחים לחלוטין וללא צורך בהרשמה, מפתח, או
כרטיס אשראי. פשוט מריצים `npm start` וזה עובד.

> **הערה לשימוש בהיקף גדול:** Nominatim החינמי מיועד לשימוש קליל (לא מסחרי
> בהיקף גדול) - מדיניות השימוש שלו מבקשת לא להציף אותו בבקשות. הקוד כבר
> משתמש ב-Debounce (השהיה של כ-350 מ״ש בין הקלדה לחיפוש) כדי לשמור על כך.
> בפריסה מסחרית בהיקף גדול, מומלץ לעבור לספק תשלום (כמו Mapbox או Google
> Maps) או לארח שרת Nominatim עצמאי.

| פקודה (בתוך `server/`) | תיאור |
|---|---|
| `dotnet run` | הרצת ה-API |
| `dotnet build` | בנייה בלבד |

## תיעוד ה-API

לאחר הרצת השרת, כל נקודות הקצה מתועדות ב-Swagger UI (`/swagger`). תקציר:

| Method | Route | תיאור |
|---|---|---|
| GET | `/api/ads` | רשימת מודעות (תומך ב-`search`, `category`, `ownerId`, `lat`, `lng`, `radiusKm`, `sortBy`, `page`, `pageSize`) |
| GET | `/api/ads/{id}` | מודעה בודדת |
| POST | `/api/ads` | יצירת מודעה |
| PUT | `/api/ads/{id}` | עדכון מודעה (רק ע"י הבעלים, מזוהה בכותרת `X-Owner-Id`) |
| DELETE | `/api/ads/{id}` | מחיקת מודעה (רק ע"י הבעלים) |
| GET | `/api/categories` | רשימת הקטגוריות הזמינות |

## זיהוי משתמש ללא התחברות

האפליקציה אינה כוללת מנגנון הרשמה/סיסמה. בכניסה הראשונה נוצר בדפדפן מזהה
ייחודי (`ownerId`) הנשמר ב-`localStorage`, יחד עם שם תצוגה שהמשתמש בוחר. מזהה
זה נשלח עם כל בקשה ומשמש את השרת כדי לאפשר עריכה/מחיקה רק של מודעות שנוצרו
על ידי אותו דפדפן. פירוט מלא והנמקה נמצאים בסעיף 4.8/4.9 של מסמך האפיון.
